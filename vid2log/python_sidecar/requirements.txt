# NOTE: `tensorflow-metal` (Apple's Metal GPU plugin for Apple Silicon) is
# deliberately NOT listed here. It's an optional accelerator, and its
# released wheels routinely lag behind TensorFlow's — when the versions
# don't line up, TF doesn't just skip the plugin, it hard-fails at import
# with `NotFoundError: dlopen(... libmetal_plugin.dylib): Library not
# loaded: @rpath/_pywrap_tensorflow_internal.so`, which takes the whole
# sidecar down before it can serve a single request. CPU inference is
# perfectly adequate here (a handful of 224x224 frames per second of
# video), so a modest speedup isn't worth a dependency that can break the
# app on a routine `pip install`. If you do want to try it later, pin both
# tensorflow and tensorflow-metal to a known-compatible pair and test that
# `python -c "import tensorflow"` works before relying on it.
tf-keras
scikit-learn
